# Changelog

All notable changes are listed here, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-23

### Added
- Citadel Lag Backtest study: same-date benchmark, aligned factor regressions, decay-curve tests, figures
- Deadline Filers study: filing lag against position turnover for five funds, scripts, results and figures
- 13F Amendments study: event study, robustness checks, corrected Goodman-Bacon decomposition, results and figures
- Common Ownership study: pipeline, 112,800-row kappa panel, data-quality and entity-resolution write-ups
- `qk13f` package with tests: ownership overlap and its decomposition, data-quality checks, fuzzy company-name matching
- Continuous integration: lint and tests on Python 3.11 and 3.12
- Intra-Firm Divergence study: Friction Index scanner, butterfly charts, case-study tables and the paper
- Adaptive Pairs Trading study: Kalman-filter hedge ratio, Random Forest entry gate, figures and the paper
- Pinned requirements for the pairs study
